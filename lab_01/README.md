## Решение задачи с использованием циклов

**Условие задачи**

Дан список чисел `lst` и число `target`. Необходимо найти два элемента списка, сумма которых равна `target`, и вернуть их индексы в виде кортежа.

Если существует несколько подходящих пар, нужно выбрать пару с наименьшими индексами.

### Решение

Для поиска подходящих элементов я использовала два вложенных цикла `for`.

Первый цикл выбирает элемент списка, а второй проверяет все элементы, расположенные после него. Если сумма двух чисел равна заданному значению, функция возвращает их индексы.

```python
lst = [1, 2, 3, 4, 5, 6, 7, 8, 9]
target = 8

def two_sum(lst, target):
    if len(lst) > 1:
        for i in range(len(lst) - 1):
            for j in range(i + 1, len(lst)):
                if lst[i] + lst[j] == target:
                    return (i, j)
    return ()

print(two_sum(lst, target))
```

**Результат выполнения:**

```text
(0, 6)
```

Числа 1 и 7 в сумме дают 8. Их индексы — 0 и 6.

Если подходящая пара отсутствует, функция возвращает пустой кортеж.

Сложность данного алгоритма — O(n²), так как используются два вложенных цикла.

## Усложнение 1. Поиск с использованием словаря

### Решение

Во втором варианте я использовала словарь, чтобы не проверять каждую возможную пару элементов.

Программа последовательно проходит по списку. Для каждого числа вычисляется значение, которого не хватает до заданной суммы.

Если такое число уже находится в словаре, функция возвращает индексы найденной пары. В противном случае текущее число и его индекс добавляются в словарь.

```python
lst = [1, 2, 3, 4, 5, 6, 7, 8, 9]
target = 8

def two_sum_hashed(lst, target):
    num_map = {}

    for i in range(len(lst)):
        complement = target - lst[i]

        if complement in num_map:
            return (num_map[complement], i)

        num_map[lst[i]] = i

    return ()

print(two_sum_hashed(lst, target))
```

**Результат выполнения:**

```text
(2, 4)
```

В данном случае программа находит числа 3 и 5, сумма которых равна 8. Их индексы — 2 и 4.

В среднем сложность такого алгоритма составляет O(n), поскольку список проходится один раз, а поиск в словаре обычно выполняется быстро.
